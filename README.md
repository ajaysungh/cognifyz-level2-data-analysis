# Cognifyz Data Analysis Internship – Level 2

This repository contains the four Level 2 restaurant-data-analysis tasks.

## Tasks
1. Restaurant Ratings
2. Cuisine Combination
3. Geographic Analysis
4. Restaurant Chains

## Folder structure
- `Task_1_Restaurant_Ratings/` – rating distribution and average votes
- `Task_2_Cuisine_Combination/` – cuisine combinations and rating comparison
- `Task_3_Geographic_Analysis/` – latitude/longitude analysis and concentration cells
- `Task_4_Restaurant_Chains/` – repeated restaurant names, ratings and popularity
- `data/` – original Cognifyz CSV dataset
- `outputs/` – generated charts and CSV summaries
- `requirements.txt` – Python dependencies

## How to run
1. Put the original Cognifyz CSV dataset in `data/`.
2. Open each `.ipynb` notebook in Jupyter Notebook, JupyterLab or Google Colab.
3. Run all cells from top to bottom.
4. Check the charts, tables and conclusions.
5. Keep the generated outputs in `outputs/`.
6. Create the final ZIP and submit it through the official Cognifyz submission form.

## Important
The notebooks calculate results directly from the supplied dataset; numerical results are not hard-coded.
